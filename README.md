# Lagos Rent Prediction Project:

# Objective:

The objective of this project is to build a machine learning model that predicts property rental prices in Lagos.

## Business Value:

1. Renters identify fair market value
2. Real estate agents price properties competitively
3. Proptech platforms improve recommendations
4. Developers assess profitable neighborhoods

## Conclusion:

This machine learning model is advantageous to anyone who has just moved to Lagos; job seekers, corp members, japada persons, students, or anyone who wants their own space.
